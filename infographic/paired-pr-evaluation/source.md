# One test uses two distinct PRs

Select two similar, unseen PRs. Exclude previously exposed acceptance PRs.
Freeze source revisions and independently checked questions.
Prebuild both tool outputs for each PR before assignment.
Randomize which PR receives each condition. Randomize reading order.

Baseline: GitHub + Lens CI.
Application: GitHub + PRC.

Read each PR once. Use only its assigned aid.
Answer three questions per PR. Reading deadline: 20 minutes per PR.
Save familiarity and cross-tool exposure as deviations.
Close the study before grading. Grade without condition labels.
Multiple choice: 0 or 1. Short answers: 0, 0.5, or 1.
Compare comprehension within each pair. Record time separately.
Artifact acceptance is separate from usefulness evaluation.
Small pilots provide exploratory evidence, not release proof.
