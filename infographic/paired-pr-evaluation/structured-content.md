# One test uses two distinct PRs

Preparation layer: Select two similar, unseen PRs. Freeze revisions and checked questions. Prebuild both tool outputs.
Assignment layer: Randomize condition and reading order.
Two equal review cards: Baseline: GitHub + Lens CI. Application: GitHub + PRC.
Reading layer: Read each PR once. Three questions each. 20 minutes per PR. Use only the assigned aid.
Scoring layer: Close before grading. Hide condition labels. Multiple choice: 0 or 1. Short answers: 0, 0.5, or 1.
Analysis layer: Compare comprehension within each pair. Record time and deviations separately.
Separate callout: Artifact acceptance is separate. Small pilots provide exploratory evidence, not release proof.
