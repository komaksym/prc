# System View: one PR, five parts

## Overview
Draft PR #11 explains swarm-deploy #116 as named system parts, with no code on screen.

## Learning Objectives
The viewer will understand:
1. What a System View shows
2. How the layout was picked
3. What passed and what is open

---

## Section 1: The exploded PR (center)

**Key Concept**: The PR is shown as five parts lifted out of one base.

**Content**:
- Each part is a box: gitops/git, compose loader, init job check, shared/faults and compose errors.
- Load returns one type (compose loader to compose errors).
- no code on screen

**Visual Element**: isometric exploded view; a flat base plate labelled with the PR, five isometric blocks floating above it with thin dashed lift lines, one amber arrow from compose loader to compose errors.

**Text Labels**:
- Base plate: "swarm-deploy #116"
- Blocks: "gitops/git", "compose loader", "init job check", "shared/faults", "compose errors"
- Arrow: "returns one type"

## Section 2: How it was built (left callouts)

**Key Concept**: An arena picked the layout; the result is a video and a page.

**Content**:
- three agents each drafted a different layout
- A judge agent picked the parts map.
- an 81-second narrated video and the matching page

**Visual Element**: two callout boxes joined to the base plate with callout lines ending in dots; small icon of three cards with one checked; small icon of a play button and a page.

**Text Labels**:
- "Arena: 3 layouts"
- "parts map won"
- "81-second video + page"
